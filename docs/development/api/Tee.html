Tee¶

class ufedmm.Tee(*files)[source]¶

Allows the use of multiple outputs in an OpenMM Reporter.

Parameters:

streams). (A list of valid outputs (file names and/or output)

Example

>>> import ufedmm
>>> import tempfile
>>> from sys import stdout
>>> file = tempfile.TemporaryFile(mode='w+t')
>>> print('test', file=ufedmm.Tee(stdout, file))
test
>>> file.close()
